# Laboratorio de Inteligencia Artificial

## Descripción del proyecto

Este repositorio contiene un laboratorio práctico relacionado con la Inteligencia Artificial, desarrollado como parte de mi formación académica.

El objetivo de este trabajo es aplicar y explorar diferentes conceptos y técnicas de Inteligencia Artificial mediante ejercicios prácticos, experimentación y análisis de resultados.

## Objetivos

- Comprender los conceptos fundamentales de la Inteligencia Artificial.
- Aplicar técnicas y herramientas relacionadas con esta disciplina.
- Desarrollar ejercicios prácticos mediante Python y Jupyter Notebook.
- Analizar los resultados obtenidos durante el laboratorio.
- Adquirir experiencia práctica en el desarrollo de proyectos de IA.

## Contenido del repositorio

- `laboratorio.ipynb`: Notebook de Jupyter que contiene el desarrollo del laboratorio, el código y los resultados obtenidos.

## Tecnologías y herramientas utilizadas

- Python
- Jupyter Notebook
- Inteligencia Artificial

## Desarrollo del laboratorio

El laboratorio se ha desarrollado utilizando Jupyter Notebook, combinando explicaciones, código y resultados para documentar el proceso de trabajo y facilitar la comprensión de los ejercicios realizados.
